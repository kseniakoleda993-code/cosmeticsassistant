# Каталог косметики

Цены взяты из списка товаров, предоставленного 21 ноября 2026 года. Они ориентировочные и указаны в BYN. Большинство фото предоставлены вместе со списком. Источники замен указаны ниже. Для загрузки в Telegram фото сохранены в JPEG без исходных метаданных.

В `products.tsv` пять колонок без заголовка. Разделитель — табуляция.

1. Позиция из меню.
2. Бюджет из меню.
3. Название для подписи к фото.
4. Цена в копейках BYN. Например, `2800` соответствует `28.00 BYN`.
5. Имя фотографии из папки `photos`.

На каждую из 19 позиций нужны две строки с разными бюджетами. Цена варианта «средний» должна быть меньше цены варианта «выше среднего». После изменения каталога перезапусти бота.
